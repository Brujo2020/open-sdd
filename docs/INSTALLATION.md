# Installation

This page moved: the single install guide is **[INSTALL.md](INSTALL.md)** — `npx`, global, container,
from a clone (including the `install.sh` and `install-global.sh` helpers), what the installer writes,
verify, upgrade, uninstall and offline installs.

The shortest path:

```bash
npx @brujo2020/open-sdd up            # the plan for this repository — nothing is written
npx @brujo2020/open-sdd up --write    # apply it, then `doctor` prints the measured verdict
```

The package is the scoped `@brujo2020/open-sdd`; the unscoped name does not exist on npm.
